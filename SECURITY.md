# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please follow these steps:

1. **Do not** open a public issue
2. Email the maintainers with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

3. Allow reasonable time for a response before disclosure

## Security Best Practices

When using SSR Doctor in your project:

- Keep dependencies up to date
- Review ESLint rules output carefully
- Use the CLI in CI/CD pipelines to catch issues early
- Report false positives to help improve detection

## Disclosure Policy

When we receive a security report:

1. We will confirm receipt within 48 hours
2. We will provide an initial assessment within 7 days
3. We will work on a fix and keep you updated
4. We will credit you in the security advisory (unless you prefer to remain anonymous)

Thank you for helping keep SSR Doctor and its users safe!
